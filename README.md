# English Adventure v1

Upload index.html, manifest.json, sw.js and icon.svg to the root of a GitHub Pages repository. Open the Pages URL. Two or more child profiles can be created. Each profile has its own stars, progress and reward requests.

Features: six levels, picture vocabulary, letter sounds, listening via browser speech synthesis, spelling, sentence ordering, reading comprehension, writing, study/test modes, star bank, parent approval, local persistence, installable PWA.

Important limitations: the illustrations are emoji, not commissioned images. Speech depends on installed browser voices and may require network or installed voices. Rewards do not pay real money: parents fulfill approved rewards separately. Email uses a mailto link and requires a person to send the message; it is NOT automatic. Parent PIN is only a light UI barrier, not security. LocalStorage does not sync between devices and can be erased. Daily star limit: 30; each unique question earns stars only once. This is a working first version, not a professionally validated curriculum or placement test.
